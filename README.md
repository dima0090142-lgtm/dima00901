# Тату-Культ — Telegram-бот и мини-приложение для записи

Мини-приложение в стиле сайта tattookult.ru, которое открывается прямо в Telegram.

**Что умеет клиент:**
- оставить заявку: имя, телефон (можно взять из Telegram одной кнопкой), идея, размер, место на теле, цвет
  и **фото-референс** — картинка-пример или фото места;
- **«Мои записи»**: ближайший сеанс (дата, время, как добраться, написать мастеру), статус предоплаты,
  заявки в работе, история сеансов и памятка по уходу; на главной — плашка «Ваш сеанс»;
- посмотреть работы мастера, акции, «Путь к вашей татуировке», информацию о салоне и частые вопросы;
- получить подтверждение записи, напоминание о сеансе и памятку после сеанса.

**Что умеет администратор (без программирования, прямо в боте, команда `/admin`):**
- 📋 **Заявки**: новые заявки приходят сразу. Кнопки «Назначить сеанс», «Связалась», «Отклонить».
- 📅 **Сеансы**: список ближайших, отмена.
- ❓ **«Пришёл ли клиент?»**: через 30 минут после начала сеанса бот спросит и предложит кнопки «Пришёл» и «Не пришёл».
- 📣 **Рассылка**: любое сообщение (текст, фото, видео) всем подписчикам бота.
- 🔥 **Акции**: добавить или удалить; после добавления бот предложит сразу разослать акцию.
- ❓ **FAQ**: добавить или удалить вопрос.
- 🖼 **Портфолио**: просто пришлите фото в бот, и они появятся в галерее. Там же просмотр и удаление.
- ✏️ **Тексты**: «О салоне», «Адрес», «Контакты».
- 📢 **Канал** (в «📣 Продвижение»): посты любого вида (текст, фото, видео) с предпросмотром и кнопкой
  «Записаться», публикация сразу или по расписанию, список запланированных. Канал меняется прямо в боте
  (бот проверит, что он администратор). Если постов давно не было — около 11:00 бот напомнит и предложит идеи,
  по понедельникам спросит, что интересного было на неделе. Посты, опубликованные в канале вручную, тоже учитываются.
- ✨ **ИИ-помощник** (через AI-шлюз: `AI_BASE_URL`, `AI_API_KEY`, `AI_MODEL`): пишет пост по фото работы или теме, предлагает идеи с учётом
  акций, сезона и прошлых постов, улучшает ваш текст. Всё сначала приходит черновиком — публикуете только вы.
- 👥 **Клиенты** — база клиентов по номеру телефона: поиск, карточка с историей сеансов и заметкой,
  добавление вручную (контакт из Telegram или «Имя +7…»), запись на сеанс из карточки, сообщение клиенту.
  Клиенты из заявок попадают в базу сами. Клиенту без Telegram-связи отправляется ссылка-приглашение —
  после неё он получает подтверждения, напоминания, рассылки и памятку.
- 📨 **Памятка после сеанса** — уходит клиенту автоматически, когда вы отмечаете «✅ Пришёл» (текст — в «✏️ Тексты»).
- 📢 **Пост в канал**: бот опубликует в канале пост с кнопкой «Записаться на тату».

## Запуск на Amvera (рекомендуется)

### 1. Подготовьте бота
1. Откройте [@BotFather](https://t.me/BotFather) → `/mybots` → выберите бота → **API Token** → **Revoke** и получите **новый** токен. Старый токен засветился в переписке, его лучше заменить.
2. Узнайте свой Telegram ID: напишите [@userinfobot](https://t.me/userinfobot), он пришлёт число вида `123456789`.

### 2. Создайте проект на Amvera
1. Зарегистрируйтесь на [amvera.ru](https://amvera.ru) и создайте новый проект типа **«Приложение»**.
2. Подключите этот репозиторий GitHub (или загрузите файлы через `git push`, как подскажет Amvera). Настройки сборки берутся из файла `amvera.yml` автоматически.
3. В разделе переменных окружения добавьте:

   | Переменная | Значение |
   |---|---|
   | `BOT_TOKEN` | новый токен бота (добавьте как **секрет**) |
   | `ADMIN_IDS` | ваш Telegram ID; несколько через запятую |
   | `CHANNEL_ID` | `@GameCubeVDK` (потом замените на основной канал) |
   | `DATA_DIR` | `/data` |
   | `WEBAPP_URL` | заполните на шаге 4 |

4. Во вкладке **«Домены»** включите бесплатный домен (вида `https://имя-проекта.amvera.io`). Скопируйте его в переменную `WEBAPP_URL` и перезапустите приложение.

> База данных и фотографии хранятся в папке `/data`, поэтому при обновлениях они не теряются.

### 3. Настройте мини-приложение в BotFather
В [@BotFather](https://t.me/BotFather): `/mybots` → ваш бот → **Bot Settings** → **Configure Mini App** → **Enable Mini App** → укажите тот же адрес, что в `WEBAPP_URL`.

После этого ссылка `https://t.me/имя_бота?startapp` открывает приложение напрямую. Её и использует кнопка в канале.

### 4. Подключите канал
1. Добавьте бота в канал **администратором** с правом публиковать сообщения.
2. Напишите боту `/admin` → **📢 Пост в канал** → выберите стандартный текст или пришлите свой.
3. Закрепите этот пост в канале. Готово! 🎉

### 5. Проверьте
- Напишите боту `/start`: появятся кнопка «Записаться» и кнопка меню рядом с полем ввода.
- Отправьте тестовую заявку: она придёт вам в бот.
- Нажмите «📅 Назначить сеанс» и введите дату, например `12.10 15:30`.

## Как обновить приложение
Amvera связана с GitHub через вебхук (событие **Push**, ветка `claude/telegram-tattoo-booking-app-u1ynn6`).
Каждый `git push` в эту ветку автоматически пересобирает и перезапускает приложение.

Если сборка не началась: GitHub → **Settings** → **Webhooks** → вебхук → **Recent Deliveries** —
там видно, дошёл ли запрос до Amvera и что она ответила.

## Запуск на своём компьютере (для разработки)
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполните BOT_TOKEN и ADMIN_IDS
python main.py
```
Приложение откроется на http://localhost:8080. Отправить заявку можно только из Telegram: сервер проверяет подпись Telegram, это защита от спама.

## Запуск на VPS (альтернатива)
Понадобятся домен и HTTPS: Telegram открывает мини-приложения только по `https://`. Проще всего поставить [Caddy](https://caddyserver.com), он сам получит сертификат:
```
tattoo.example.ru {
    reverse_proxy 127.0.0.1:8080
}
```
Бот запускается командой `python main.py`. Чтобы он работал постоянно, оформите его как сервис systemd.

## Устройство проекта
```
main.py              — точка входа: бот + веб-сервер + напоминания
app/config.py        — настройки из переменных окружения
app/db.py            — база данных SQLite
app/web.py           — API для мини-приложения (контент, приём заявок)
app/handlers/user.py — /start и ответы клиентам
app/handlers/admin.py— панель администратора
app/reminders.py     — напоминания и вопрос «Пришёл ли клиент?»
webapp/              — само мини-приложение (HTML/CSS/JS)
```
